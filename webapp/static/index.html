Input package format 
cv_assurance_input.zip
├── images/                     required
│   ├── image_001.jpg
│   └── …
├── annotations/                required
│   └── annotations.json        required · COCO format
├── model/                      optional
│   ├── model.npz | model.onnx | model.pt        served model
│   └── trusted_model.*         trusted reference (optional)
├── streams/                    optional
│   └── <stream_name>/  images (+ metadata.json)
└── metadata/                   optional

Without a model, only Part 1 (data integrity) and Part 5 run; Parts 2–4 are reported as not executed. Without a separate trusted reference, the served model is compared against itself.
